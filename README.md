# Brainbox

A personal knowledge repository containing various tools, configurations, and resources.

## 📁 Directory Structure

### `adblock/`
Browser ad-blocking configurations:
- **`ublacklist.txt`** - uBlacklist configuration with AI blocklist source
- **`ublock.txt`** - uBlock Origin rules for Reddit app ads

### `bashrc/`
Shell configuration:
- **`bashrc`** - Custom bash aliases and shortcuts for system management, package handling, and productivity

### `chatgpt_prompts/`
AI prompt templates:
- **`geoguesser.md`** - Prompt for geographic location analysis from images
- **`talspråk.md`** - Swedish prompt for casual, conversational writing style

### `cursorrules/`
Cursor IDE configuration:
- **`comprehensive.cursorrules`** - Complete development guidelines for AI collaboration
- **`python-best-practices.cursorrules`** - Python-specific coding standards and practices

### `espanso/`
Text expansion configuration:
- **`config/default.yml`** - Main espanso configuration
- **`match/base.yml`** - Core text expansions (dates, URLs, brackets, emails)
- **`match/chatgpt.yml`** - AI prompt templates for ChatGPT/Bard
- **`match/cube.yml`** - ServiceNow HTML formatting shortcuts
- **`match/smileys.yml`** - ASCII art and emoji expansions

### `recept/`
Recipe collection:
- **`muskelgröt.md`** - High-protein oatmeal recipe with ingredients and variations

### `trading/`
Trading strategies and tools:
- **`daytrading.md`** - Technical analysis strategy using EMAs and momentum indicators
- **`goldenline_enhanced.pine`** - Pine Script indicator for TradingView with SMMA calculations

### `träning/`
Fitness and nutrition:
- **`100_dieten.md`** - Calorie density diet principles (≤100 kcal/100g focus)
- **`baby_bear_complex.md`** - Kettlebell workout progression routine
