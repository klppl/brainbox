Lightweight dump of configs, prompts, and notes I re-use.

- bashrc: shell aliases and helpers.
- chatgpt_prompts: prompt templates (GeoGuesser, Swedish casual tone).
- cursor: Cursor IDE workspace notes, Cursor AI coding guidelines.
- espanso: text expansion packs (base, chatgpt, cube, smileys).
- irc: Halloy client config.
- recept: quick recipes (muskelgröt, stekt ris/ägg, råraka).
- trading: strategies and Pine scripts (daytrading, EPIC_STORSI, goldenline_enhanced).
- träning: diet and kettlebell routines (100_dieten, baby_bear_complex).
